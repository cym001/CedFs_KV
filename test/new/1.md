# KV Cache 热度均衡与迁移算法

## 1. 问题背景

在分布式 KV Cache 系统中，不同实例（Instance）承载的 KV Block 访问压力可能不均衡，导致：

* 部分节点过载（热点节点）
* 部分节点空闲（冷节点）
* 整体吞吐下降

目标是通过 **KV Block 迁移 / 副本扩展** 实现负载均衡。

---

## 2. 核心建模

### 2.1 KV Block 热度

H(k)=\sum_i u_i(k)

* (u_i(k))：实例 i 对 block k 的访问次数
* (H(k))：block k 的总访问热度

---

### 2.2 实例负载

L_i=\sum_{k:i\in I_k}\frac{H(k)}{|I_k|}

* (I_k)：block k 的副本实例集合
* (|I_k|)：副本数
* 每个副本平均分担该 block 的访问压力

---

### 2.3 优化目标

\min CV(L_1,L_2,...,L_N)

* CV（变异系数） = 标准差 / 均值
* 目标：最小化实例负载差异

---

## 3. 数据结构

```python
Block:
    id
    heat            # H(k)
    replicas        # I_k

Instance:
    id
    load            # L_i
    blocks
```

## 4. 算法流程

### Step 1：统计 Block 热度

```python
for request in requests:
    for block k in request.blocks:
        H[k] += 1
```

---

### Step 2：计算实例负载

```python
for i in instances:
    L[i] = 0

for k in blocks:
    r = len(I[k])
    for i in I[k]:
        L[i] += H[k] / r
```

---

### Step 3：计算 CV

```python
def calc_cv(L):
    mean = avg(L)
    std  = stddev(L)
    return std / mean
```

---

### Step 4：选择迁移候选

```python
src = argmax(L)   # 最热节点
dst = argmin(L)   # 最冷节点
```

---

### Step 5：评估迁移收益

```python
def evaluate(k, src, dst):

    if dst in I[k]:
        return -inf

    old_r = len(I[k])

    old_share = H[k] / old_r
    new_share = H[k] / (old_r + 1)

    L_sim = L.copy()

    # 原副本节点负载下降
    for i in I[k]:
        L_sim[i] = L[i] - old_share + new_share

    # 新副本节点增加负载
    L_sim[dst] += new_share

    return calc_cv(L) - calc_cv(L_sim)
```

---

### Step 6：执行迁移（贪心）

```python
best_k = None
best_gain = 0

for k in blocks_of(src):

    gain = evaluate(k, src, dst)

    if gain > best_gain:
        best_gain = gain
        best_k = k

if best_k:
    replicate(best_k, dst)
```

---

## 5. 完整循环

```python
while True:

    update_heat()
    compute_load()

    if calc_cv(L) < threshold:
        continue

    src = argmax(L)
    dst = argmin(L)

    candidates = topk_hot_blocks(src, K=50)

    best_k = None
    best_gain = 0

    for k in candidates:
        gain = evaluate(k, src, dst)

        if gain > best_gain:
            best_gain = gain
            best_k = k

    if best_k:
        replicate(best_k, dst)
```

---

## 7. 算法特点

* 基于 **热度驱动**
* 使用 **副本分摊负载**
* 目标函数清晰（CV最小化）
* 可在线增量优化
* 适用于大规模 KV Cache 系统

---

## 8. 适用场景

* LLM 推理（KV Cache）
* Prefix Cache 共享
* 长上下文服务
* 分布式推理系统（vLLM / TensorRT-LLM 等）

---

## 9. 核心总结

本算法本质是：

> **通过复制热点 KV Block，将访问压力从热点节点扩散到冷节点，实现负载均衡。**

而不是简单的数据迁移。
